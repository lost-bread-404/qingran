# 清然 iOS：你需要做的步骤

完整顺序（先自己的域名和自动发布，再装 iPhone）在仓库根目录 **[操作说明.md](../操作说明.md)**。网站还没上线时，先做那一份的第一部分。

仓库里的 iOS 工程已经写好。我这边没有 Mac，没法替你点「安装到 iPhone」。下面是「网站已经在自己的域名上」之后，把壳装到手机。


做完后：主屏幕会有一颗「清然」图标。麦克风权限在 **设置 → 清然**。点电话之后，切到别的软件也可以继续说、继续听。

不上架。只装给你自己。

---

## 开始之前你要有

1. **一部 iPhone**（iOS 16 或更新）
2. **一台 Mac**（Windows 装不了 Xcode）
3. **Apple 开发者账号**（一年 99 美元，用你平时那个 Apple ID 注册即可）
4. **一条数据线**（第一次必须插上）
5. **清然已经发布后的网页地址**（你现在用的那个 `xxx.grok.me`）

没有 Mac：请一个有 Mac 的人按这份说明帮你装一次。装上以后日常打开不再需要电脑。

---

## 第一步：发布这次网页

原生壳打开的是**已经发布的清然网址**，不是 GitHub 源码。记忆也在那个网址上。

1. 把 `ios-microphone` 这一支发布到你现在用的那个清然站点（和以前发布清然一样）。
2. 用 Safari 打开一次，确认还能打电话、记忆还在。
3. 复制地址栏完整链接，后面要贴进 App。

没发布就去装 App，打开会是旧页面，系统通话接不上。

---

## 第二步：加入 Apple 开发者计划（99 美元）

1. 在 iPhone 或 Mac 打开：https://developer.apple.com/programs/enroll/
2. 用你的 Apple ID 登录。
3. 选 **Individual（个人）**。
4. 按提示付钱、同意协议。
5. 可能要验证身份，通过通常几小时，有时要一两天。
6. 收到「Welcome to the Apple Developer Program」再做后面的步骤。

在这里付。不要买别人的账号。

---

## 第三步：Mac 上安装 Xcode

1. 打开 Mac App Store，搜 **Xcode**，安装（很大，留出时间和磁盘）。
2. 打开一次 Xcode，同意条款，等它装完附加组件。
3. 菜单 **Xcode → Settings… → Accounts**。
4. 点左下角 **+**，选 **Apple ID**，登录刚才那个开发者账号。
5. 登录成功后右边应出现 **Team**，名字后面有你的个人团队。

---

## 第四步：拿到这份工程

任选一种：

**A. 会用 Git**

```
git clone https://github.com/lost-bread-404/qingran.git
cd qingran
git checkout ios-microphone
```

**B. 不会用 Git**

1. 打开 https://github.com/lost-bread-404/qingran
2. 左上角分支选 `ios-microphone`
3. 绿色 **Code** → **Download ZIP**
4. 解压

---

## 第五步：用 Xcode 打开并签上你的名字

1. 进入文件夹，打开：`ios/Qingran/Qingran.xcodeproj`  
   （双击即可，要用 Xcode 打开，不要用别的编辑器。）
2. 左边列表最上面点蓝色的 **Qingran** 项目。
3. 中间选 TARGETS 里的 **Qingran**。
4. 打开 **Signing & Capabilities**。
5. 勾选 **Automatically manage signing**。
6. **Team** 下拉，选你的付费个人团队。  
   如果是灰色或报错，回到第三步确认 Accounts 已登录，且开发者计划已经通过。
7. **Bundle Identifier** 保持 `app.qingran.ios`。  
   若提示已被占用，改成 `app.qingran.你的名字` 这种不会撞车的。
8. 确认 **Signing Certificate** 变成 Apple Development，没有红字。

---

## 第六步：第一次装到 iPhone

1. 用数据线把 iPhone 连上这台 Mac。
2. iPhone 弹出「信任这台电脑」→ 信任，输入密码。
3. iPhone：**设置 → 隐私与安全性 → 开发者模式** → 打开 → 重启。  
   若没有「开发者模式」：先在 Xcode 顶部设备列表里选中你的 iPhone，再回设置里找。
4. Xcode 窗口最顶部，设备从模拟器改成 **你的 iPhone 名字**。
5. 点左上角三角形 **Run**（或 Command + R）。
6. 第一次较慢。成功后 iPhone 主屏幕出现「清然」。
7. 若提示「不受信任的开发者」：  
   **设置 → 通用 → VPN 与设备管理** → 点你的 Apple ID → **信任**。
8. 点开清然。

---

## 第七步：贴网址、开麦克风

1. 第一屏让你贴清然网页地址。贴第一步复制的那个，点 **打开清然**。
2. 看到熟悉的清然界面后，点 **电话**。
3. 系统会问麦克风 → **允许**。
4. 以后要改开关：**设置 → 清然 → 麦克风**。  
   （这就是你以前在网页里找不到的那个位置。）
5. 打电话过程中切到别的软件、锁屏，绿条或通话界面还在，就可以继续说。
6. 从多任务里把清然划掉 = 挂断。不要划掉，只是切走即可。

地址贴错了、记忆空了：关掉清然，**设置 → 清然 → 网址** 改成正确的 grok.me，再完全划掉 App 重新打开。

---

## 之后日常

- 不用再连电脑。像普通 App 一样点开。
- **改清然的功能、文案、通话逻辑：不用重装 iPhone。** 见下面「网页怎么更新到手机里」。
- 只有改了 `ios/` 里面的原生壳（麦克风、CallKit），才需要再用 Xcode 点一次 Run。
- 证书一年有效。明年在 https://developer.apple.com/account 续费 99 美元，再用 Xcode 连一次手机点 Run，就能再签一年。不续费的话到期后 App 会打不开。

---

## 网页怎么更新到手机里（这就是 continuous deployment）

iPhone 上的「清然」不是把代码封死在安装包里。它打开的是你贴进去的那个 grok.me 网页。所以：

**GitHub 上改代码 → 发布到同一个 grok.me → 手机里自动变成新版。不用重装 App。**

具体三步：

1. 代码推到 GitHub（`ios-microphone` 或你之后用来发布的分支）。我在这边改完也会帮你 push。
2. **发布网页到你现在用的那个清然地址。** 还是在 Grok 里点发布，跟以前一样。必须是同一个 grok.me，记忆才还在。GitHub 自己不会自动发布到 grok.me，这一下只能你点（或跟我说「发布」）。
3. 手机上：如果当时没在打电话，把清然切到前台，或划掉再打开，就会拉最新网页。打电话过程中不会刷新，以免把通话冲掉。

不要把地址改成另一个 grok.me 或 Vercel 链接，库是空的。

---

## 不要做的事

- 不要把这个 App 提交到 App Store。
- 不要用 TestFlight 公开链接。
- 不要改网页地址到另一个 grok.me，记忆不会跟着过去。

## 常见问题

**Xcode 说 Team 为空 / 免费个人团队**  
开发者计划还没通过，或 Accounts 里登的不是付钱那个 Apple ID。

**点 Run 失败，报 signing / provisioning**  
Bundle Identifier 换一个，Team 再选一次，勾 Automatically manage signing。

**App 能开，但没有麦克风这一项**  
还没点过电话、还没弹过允许。先点电话让它问一次。

**切到后台仍然不能说话**  
确认是打开主屏幕上的「清然」App，不是 Safari 里的网页，也不是「添加到主屏幕」的那个图标。系统权限只给原生壳。

**没有 Mac**  
必须找一台装一次。我无法从这里把安装包推到你的 iPhone。
