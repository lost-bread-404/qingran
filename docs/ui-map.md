# 设置在哪

从设置首页进去，任何一项最多再点两次。平时只看，不用调：模型自己学。

设置首页每一项下面写着它在程序里起什么作用（她 2026-10-03 要的：一眼看懂每个板块管什么）。

| 页面 | 里面有什么 | 在程序里起什么作用 |
|---|---|---|
| 人设 | 清然：声线、身份、人设、亲密设定。其他角色：每人一张卡（名字、声线、人设），可以加、可以删。其他人的声线（没写成角色的人）。每个声线旁边有 ▶，选了就念一句；最下面「试听声线」能把所有声线挨个听一遍 | 每轮回复（和夜里整理）都带着全部：清然的，再接「其他人物：【林泽】……」。谁的「名字：」那一段用谁的声线念 |
| 记忆 | 运行记忆、回复带不带 dossier、夜里整理用哪个模型；dossier（顶上「现在整理一次」随时可点，好了自动换上；可改、有字数上限和版本历史）；你的抱怨 | dossier 每轮都带 |
| 回复 | Claude 分流开关（关掉就全部 Grok 回）、现在谁在回（Claude / Grok，只显示）、Claude 用哪个模型、Grok 用哪个模型（旁边是平均回复时间）、离开多久换回 Claude；上下文至少几条、温度（只用在 Grok）、人设放在哪 | 每轮回复的设置 |
| 主动消息 | 主动找你用哪个模型（默认 grok-4.20 reasoning，附每次平均用时）、开关、测试通知、现在让他想起你、记录 | 你不说话 45 分钟、3 小时……时他想一次要不要来找你 |
| 声音和听力 | 语速、静音、通话时挂断键两边点一下加上的话、听力低 / 中 / 高 | 他念得多快、打电话时怎么听你 |
| 数据 | 故事线、导出 / 导入（初始化）、清空聊天、退出 | 故事线是记忆的起点：点「保存，重新放进记忆」就重新切成回忆，换掉上次切的，夜里整理的不动 |
| 高级 → 指令 | 发给模型的每一个字（每轮回复和主动找她的材料怎么排（指令本身都在人设里），夜里整理、月报、材料的写法）和每一步用哪个模型；每一步（材料的写法除外）都有「看发出去的样子」，看即将发出的完整原文；不列每个 {…} 是什么（她 2026-10-06：又长又没用） | 调试用 |
| 高级 → 记录 | 从上到下：重放对比（先选哪一天（默认最近 60 句，往前 45 天里有她说话的每一天都能选，清空聊天之前的也在；一天里的句子按时间从早到晚），再选那天的一句；他看到的是那一句之前、那一天的全部对话，和真回复时一样；B 换人设、亲密设定、人设位置或模型：模型和设置 → 回复一样从列表里选，Claude 和 Grok 都有，带思考强度；A、B 上下排）、改动记录（人设、亲密设定、身份）、调用记录（上面一排按步骤筛选，「手改」看她手改过的；每次一条，点开是发出去的全文和回的；会一直变长，所以放最下面，她 2026-10-09 定的） | 调试用 |
| 高级 → 费用 | 只记账 | |
| 高级 → 听力参数 | 听力具体滑块、keyterm、标注 | 调试用 |

日记页只有每天的时间线和月报。

聊天主屏幕：她说过的每一句旁边有铅笔，改最后一句清然重新回一次（以前的回答还能翻页），改前面的从那一句重新聊、后面的收起来；清然每条回复旁边也有铅笔，改了就地保存、不重新回（看得到朗读语气标签）；「打字」里可以发照片（最多 4 张）；清然每条回复下面一个大拇指（回得好）、一个倒拇指（点开「差在哪」：标签 + 一行备注），见 [feedback.md](feedback.md)。
