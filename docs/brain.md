# 清然 brain v5（2026-09-26）

需求总表见 [requirements.md](requirements.md)，检验用的一天见 [day-example.md](day-example.md)，导入导出格式见 [state-format.md](state-format.md)。

原则：代码只结构化它自己要执行的东西（时间、做没做完），其余全是自由文本，不预设分类。一个「心思」负责所有要多想一层的事；回复只看结果，回复前不调用任何模型。

## 存什么

| | 内容 | 谁写 | 回复看得到？ | 表 |
|---|---|---|---|---|
| 原话 | 全部消息，只追加，永久保存 | 通话 | 最近 N 条（上下文长度） | `qingran_messages` |
| 人设 / 身份 / 故事线 / 亲密设定 | 她写的 | 她 | 人设看得到；亲密设定只在勾了 intimate 的模式里；身份、故事线给心思和夜里整理 | `qingran_profile.data` |
| **心里** | 一两句：他自己此刻的情绪和欲望。不写对她的分析（她此刻怎样由回复看对话和记忆读；深一层的理解夜里写进记忆） | 心思、夜里整理、她 | 看得到 | `qr_inner.now_text` |
| **眼前这一件** | 一句话：打算单上现在该推进的那一件，写要做成什么。什么时候提、怎么带，回复看当下自己决定 | 心思、她 | 看得到 | `qr_inner.focus` |
| **打算** | 这一天的打算单，按先后排（按写入顺序存）；自由文本，时间可有可无，可以带条件。从她的目标和难处、他自己想要的、欠着的来 | 心思、夜里整理、她 | 看不到 | `qr_reach_plans`（`at` 可空，`done_at` 为空 = 待办） |
| **今天 / 每天** | 每天一段文字。今天那一段：她的事、他说过编过的关于自己的事、还欠着的事，她沉默时心思整段重写；过了凌晨，夜里整理把它定稿成那天她的时间线 | 心思（她沉默时）、夜里整理、她 | 今天那段看得到 | `qr_days` |
| **记得的** | 一份文档，不设固定栏目，按「会不会改变他以后怎么做」取舍，有字数上限；每次改动留版本，夜里整理写一句改了什么 | 夜里整理、她、导入 | 全文看得到 | `qr_dossier` + `qr_dossier_versions` |
| **模式** | 她定义：名字、什么时候用、prompt、temperature、intimate、keepActions | 她；当前模式由心思和夜里整理选，选了就一直用到下一次选 | 当前模式的 prompt 和 temperature | `profile.modes` + `qr_mode_log` |

「设置 → 高级 → 指令」顶上的「运行心思和记忆整理」关掉：回复只用人设 + 当前模式 + 上下文，不跑心思和夜里整理，没有主动消息，模式在聊天页右上角手动切。

## 什么时候跑

| 流程 | 触发 | 做什么 | 代码 |
|---|---|---|---|
| 回复 | 每轮 | 回复前不调用任何模型 | `routes/api/talk.ts`、`voice/pack.ts` |
| 心思 · 刚说完话 | 每轮回复后异步 | 按这个顺序输出：`plans_changed` + 完整 `plans`、`focus`（每次都写）、`heart`（空 = 不变）、`mode`（空 = 不换）。看最近 20 条 | `voice/reflector.ts` |
| 心思 · 她沉默了 | 她最后一条消息后 45 分钟，每段沉默一次 | 同上，另外写 `today`：把「今天」整段重写，加进这一段（上次沉默之后、今天 04:00 之后，最多 120 条） | `voice/reflector.ts`、`reach.ts runWake` |
| 心思 · 到时间了 | 每 5 分钟的 wake（cron-job.org → `/api/cron/wake`）发现有打算到点 | 她最后一条消息在 10 分钟内：什么都不调用，打算留着，下一轮心思看到「到时间了」，按先后轮到它就是眼前这一件。她不在：心思再想一遍，多输出一条 `message`：找她是为了什么（空 = 不发）；原话由回复的声音写（`voice/first-word.ts`，指令「每轮回复 → 主动找她」：同样的人设、模式、记忆、心里、最近对话，外加「她已经 X 分钟没说话，是你先开口」）；发了就存进聊天、推送到 iPhone。聊天里不标「他先找你」，她还没回的他的消息前面一个小红点。到点的打算算处理完。失败重试一次，还失败就在聊天里说没发成功。每天有软上限 | `reach.ts` |
| 夜里整理 | wake 在当地 04:00–12:00 之间发现昨天还没整理 | 一次调用：整篇重写记得的（附一句改了什么）、定稿那天的时间线、明天的打算、明早的心里、明早的模式。`keepActions=false` 的模式里，他的话只留说出口的部分 | `night.ts` |
| 整理今天 | 他的心 → 「现在把今天整理进去」 | 只把今天收进记得的；今天的文字、打算、心里、模式不动 | `night.ts`（manual） |
| 清空聊天 | 她按下 | 今天还没整理进记忆的消息标 forgotten；清空心里和眼前这一件；删掉没定时间的打算。定了时间的、她加的打算和记得的保留 | `store.ts clearRecentConversation` |
| 月报 | 每月 1 日（日记页开关打开时），或日记页手动 | 读这个月每天的时间线和对话摘要写月报，只给她看 | `diary/report.ts` |

## 回复看到的（顺序）

1. 人设（+ 身份）+ 当前模式的 prompt（前面一句说明：这是基调不是规定，眼前的事和心里的感觉优先）
2. `你记得的：` + 记得的全文
3. `你心里（她看不到，你用做的事体现出来）：` + 心里 + 眼前想做的一件事
4. 亲密设定（当前模式勾了 intimate 时）
5. `今天到现在（你知道的事）：` + 今天那段文字
6. `现在是…` + 她上一次说话距现在多久 + 今天她来找他的时段
7. 最近 N 条（较早的清然回复只留说出口的话）
8. 这一句

空的块整块不放。模型回空（多半是拒绝）时依次重试：去掉心里和今天 → 再去掉记得的 → 只留人设和最近 8 条，并可换到备用模型。

## 心思看到的

人设、身份、故事线、记得的、为什么现在想（刚说完话 / 沉默了多久 / 到时间了）、时间事实、最近 7 天时间线、今天、打算单、眼前这一件、心里、模式列表、对话。

心思是控制单元（她 2026-09-26 定的）：只管全局——这一天往哪走、打算单做到了哪、下一件交给回复；不琢磨她此刻的情绪，也不写动作。对她此刻的理解由回复靠上下文和记忆，长期深度理解由夜里整理写进记忆。它每次按顺序想：今天是什么样的日子 → 过一遍打算单（做完的、用不着的、到时间的、刚才的事要加的）→ 挑出眼前这一件。什么时候提、怎么顺着当前的事带过去，由回复看当下决定，心思不替它等时机。指令在设置 → 高级 → 指令 → 内心。

## 模型

都在设置 → 高级 → 指令里按指令换。默认：回复 grok-4.2（non-reasoning）；心思 `reflect` grok-4.3 medium（主动消息找不找、为了什么由它定；原话用回复的模型写）；夜里整理 `editor` grok-4.3 medium（超时 240 秒）；月报 `report` grok-4.3 medium。

## 费用

只记账（设置 → 高级 → 费用），不在 app 里限额；xAI 预付额度就是上限。主动消息每天有软上限。见 [spend.md](spend.md)。
