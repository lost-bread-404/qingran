# 清然 brain v5（2026-09-26）

需求总表见 [requirements.md](requirements.md)，检验用的一天见 [day-example.md](day-example.md)，导入导出格式见 [state-format.md](state-format.md)。

原则：代码只结构化它自己要执行的东西（时间、做没做完），其余全是自由文本，不预设分类。一个「心思」负责所有要多想一层的事；回复只看结果，回复前不调用任何模型。

## 存什么

| | 内容 | 谁写 | 回复看得到？ | 表 |
|---|---|---|---|---|
| 原话 | 全部消息，只追加，永久保存 | 通话 | 最近 N 条（上下文长度） | `qingran_messages` |
| 人设 / 身份 / 故事线 / 亲密设定 | 她写的 | 她 | 人设看得到；亲密设定只在勾了 intimate 的模式里；身份、故事线给心思和夜里整理 | `qingran_profile.data` |
| **想法** | 心思最近一次想到的（「小猫撒娇真可爱，但药不能白吃，先哄她喝饮料再去学」）。想法要么变成打算，要么不留；只存着给她看，没有模型读它 | 心思 | 看不到 | `qr_inner.now_text` |
| **打算** | 按先后排的打算单（按写入顺序存）：她的事，和他自己想要她的事（「下午亲热」「讨回她欠的」）。自由文本，时间可有可无，可以带条件。第一件到了时间的（没写时间就是现在）是回复**现在在做**的那一件，做成了心思拿掉，下一件接上 | 心思、夜里整理、她 | 只看得到现在在做的那一件 | `qr_reach_plans`（`at` 可空，`done_at` 为空 = 待办） |
| **今天 / 每天** | 每天一段文字。今天那一段：她的事、他说过编过的关于自己的事、还欠着的事，她沉默时心思整段重写；过了凌晨，夜里整理把它定稿成那天她的时间线 | 心思（她沉默时）、夜里整理、她 | 今天那段看得到 | `qr_days` |
| **记得的** | 一份文档，不设固定栏目，按「会不会改变他以后怎么做」取舍，有字数上限；每次改动留版本，夜里整理写一句改了什么 | 夜里整理、她、导入 | 全文看得到 | `qr_dossier` + `qr_dossier_versions` |
| **模式** | 她定义：名字、什么时候用、prompt、temperature、intimate、keepActions | 她；当前模式由心思和夜里整理选，选了就一直用到下一次选 | 当前模式的 prompt 和 temperature | `profile.modes` + `qr_mode_log` |

「设置 → 高级 → 指令」顶上的「运行心思和记忆整理」关掉：回复只用人设 + 当前模式 + 上下文，不跑心思和夜里整理，没有主动消息，模式在聊天页右上角手动切。

## 什么时候跑

| 流程 | 触发 | 做什么 | 代码 |
|---|---|---|---|
| 回复 | 每轮 | 回复前不调用任何模型 | `routes/api/talk.ts`、`voice/pack.ts` |
| 心思 · 刚说完话 | 每轮回复后异步 | 按这个顺序输出：`thought`（此刻的想法，只存记录）、`plans_changed` + 完整 `plans`（想法变成单子上的事，做成的拿掉）、`mode`（空 = 不换）。看最近 20 条 | `voice/reflector.ts` |
| 心思 · 她沉默了 | 她最后一条消息后 45 分钟，每段沉默一次 | 同上，另外写 `today`：把「今天」整段重写，加进这一段（上次沉默之后、今天 04:00 之后，最多 120 条） | `voice/reflector.ts`、`reach.ts runWake` |
| 心思 · 到时间了 | 每 5 分钟的 wake（cron-job.org → `/api/cron/wake`）发现有打算到点 | 她最后一条消息在 10 分钟内：什么都不调用，打算留着，按先后轮到它，它就是回复现在在做的那一件。她不在：心思再想一遍，多输出一条 `message`：找她是为了什么（空 = 不发）；原话由回复的声音写（`voice/first-word.ts`，指令「每轮回复 → 主动找她」：同样的人设、模式、记忆、现在在做的那一件、最近对话，外加「她已经 X 分钟没说话，是你先开口」）；发了就存进聊天、推送到 iPhone。聊天里不标「他先找你」，她还没回的他的消息前面一个小红点。到点的打算不算做完：去掉时间留在单子上，成了接下来找机会做的事，做成了或心思觉得用不着了才拿掉。失败重试一次，还失败就在聊天里说没发成功。每天有软上限 | `reach.ts` |
| 夜里整理 | wake 在当地 04:00–12:00 之间发现昨天还没整理 | 一次调用：整篇重写记得的（附一句改了什么）、定稿那天的时间线、明天的打算（包括他自己想要她的）、明早的模式。`keepActions=false` 的模式里，他的话只留说出口的部分 | `night.ts` |
| 整理今天 | 他的心 → 「现在把今天整理进去」 | 只把今天收进记得的；今天的文字、打算、模式不动 | `night.ts`（manual） |
| 清空聊天 | 她按下 | 今天还没整理进记忆的消息标 forgotten；清空刚才的想法；删掉没定时间的打算。定了时间的、她加的打算和记得的保留 | `store.ts clearRecentConversation` |
| 月报 | 每月 1 日（日记页开关打开时），或日记页手动 | 读这个月每天的时间线和对话摘要写月报，只给她看 | `diary/report.ts` |

## 人称

所有给模型看的文字（人设、模式、亲密设定、指令、记得的、现在要做成的事、今天、时间线、打算、对话标签）都是清然自己的口吻：「我」是清然，「你」是 Rosie（她 2026-09-29 定的）。她发来的话照她打的原样，里面的「我」是她自己。心思和夜里整理写下的东西也照这样写（「让你吃点东西」「你睡前常常不刷牙」）。以前人设是「我 / 你」，记忆和心里却是清然第一人称、把她叫「她」，回复就跟着写出「把她抱进怀里」，像在做任务。故事线是她写的原文，用名字写，不改；给回复时标题里写明「里面的清然就是我，Rosie 就是你」。

## 回复看到的（顺序）

1. 人设（+ 身份）+ 当前模式的 prompt（前面一句「现在大致是这样的时候（是基调，场面变了就按场面来）：」）+ 两句：像真人一样说话，每次一两个动作、一两句话，只写此刻真的在做的事，她只是叫你、撒娇、应一声时一个小动作或一两个字就够（人设里的「自然简短」挡不住模型写长篇，所以指令里写明）；所有文字的人称和人设一样
2. `我们的故事（里面的清然就是你，Rosie 就是我）：` + 故事线全文（她在人设页写的那一份，原样）。夜里整理写的「记得的」回复不读，只给心思和夜里整理
3. `我心里现在要做成的事：` + 打算单上现在在做的那一件（没有就整块不放）
4. 亲密设定（当前模式勾了 intimate 时）
5. `今天到现在：` + 今天那段文字
6. 最近 N 条（清然的回复是全文，动作和话都在；两条之间隔了 30 分钟以上，插一行「（过了 X 小时 Y 分钟）」，新的早上不会读成同一个夜里）
7. `现在是…` + 我上一次说话距现在多久（放在对话后面、这一句前面）
8. 这一句

空的块整块不放。模型回空（多半是拒绝）时依次重试：去掉现在要做成的事和今天 → 再去掉我们的故事 → 只留人设和最近 8 条，并可换到备用模型。

## 心思看到的

人设、身份、故事线、记得的、为什么现在想（刚说完话 / 沉默了多久 / 到时间了）、时间事实、最近 7 天时间线、今天、打算单（标出现在在做的那一件）、模式列表、对话（每行「[时间] 我：…」或「[时间] 你：…」，我 = 清然，你 = Rosie，和其他文字同一个人称；夜里整理读的对话也这样标）。

心思就是清然的内心（她 2026-09-27 按 `day-example.md` 定的）：看着人设、记得的和眼前的互动，想出他自己此刻的想法，把想法变成打算单上的事——她的事（吃东西、学习、睡觉），和他自己想要她的（下午亲热、讨回她欠的）。一个想法要么变成单子上的一件，要么不留，不会有一句欲望每轮都挂在心里。回复每一轮只看到单子上现在在做的那一件，自己决定怎么说、怎么做；做成了心思拿掉，下一件接上。她说不要、说累了之后那件还要不要，不在指令里定规则，由心思按人设和记忆判断（她 2026-09-27：规则越细越窄，有记忆之前她抱怨一句他都还会接着哄）。模式跟着现在在做的那件走。指令在设置 → 高级 → 指令 → 内心。

心思和夜里整理写下的每一样（想法、打算、今天、记得的、时间线）都用「我 / 你」，不用「她」「Rosie」「清然」；故事线里的名字只在读的时候对上号。今天和时间线写成几点到几点在做什么的一小段，不一句一句记对话；记得的里不往后面接某一天发生了什么；我此刻的情绪不写上打算单（回复看着对话自己读）。这些是模型自己不会做的，指令里写明（2026-09-27 精简时删过，2026-09-29 放回）。

## 模型

都在设置 → 高级 → 指令里按指令换。默认：回复 grok-4.2（non-reasoning）；心思 `reflect` grok-4.3 medium（主动消息找不找、为了什么由它定；原话用回复的模型写）；夜里整理 `editor` grok-4.3 medium（超时 240 秒）；月报 `report` grok-4.3 medium。

## 费用

只记账（设置 → 高级 → 费用），不在 app 里限额。连上 SuperGrok 后，所有 xAI 调用（回复、心思、夜里整理、听写、朗读）先用订阅额度，被拒（额度用完、429、403）时同一个请求改用 API key，过一阵（15–60 分钟）再试订阅；走订阅的记录记 $0（`src/lib/lover/xai-auth.ts`）。主动消息每天有软上限。见 [spend.md](spend.md)。
