# 清然 brain v5（2026-09-25）

需求总表见 [requirements.md](requirements.md)，检验用的一天见 [day-example.md](day-example.md)，导入导出格式见 [state-format.md](state-format.md)。

原则：代码只结构化它自己要执行的东西（时间、做没做完），其余全是自由文本，不预设分类。

## 存什么

| | 内容 | 谁写 | 回复看得到？ | 表 |
|---|---|---|---|---|
| 原话 | 全部消息，只追加，永久保存 | 通话 | 最近 N 条（上下文长度） | `qingran_messages` |
| 人设 / 身份 / 故事线 / 亲密设定 | 她写的 | 她 | 人设看得到；亲密设定只在勾了 intimate 的模式里；身份、故事线给心思和夜里整理 | `qingran_profile.data` |
| **心里** | 一段自由文本：他此刻的感觉、想要她什么、怎么看她 | 心思、夜里整理、她 | 看得到 | `qr_inner.now_text` |
| **打算** | 自由文本条目，时间可有可无，可以带条件 | 心思、夜里整理、她 | 看不到 | `qr_reach_plans`（`at` 可空，`done_at` 为空 = 待办） |
| **眼前这一件** | 一句话：回复现在只做的那一件事；她在说别的事时为空 | 心思、她 | 看得到 | `qr_inner.focus` |
| **今天** | 带时间的随手记（学习段、吃饭、情绪、睡着） | 心思 | 看不到（心思看） | `qr_day_notes` |
| **每天的时间线** | 一天一小段话 | 夜里整理 | 心思看最近 7 天 | `qr_days` |
| **记得的** | 一份文档，不设固定栏目，按「会不会改变他以后怎么做」取舍，有字数上限 | 夜里整理、她、导入 | 全文看得到 | `qr_dossier` + `qr_dossier_versions` |
| **模式** | 她定义：名字、什么时候用、prompt、temperature、intimate、keepActions | 她；当前模式由心思选 | 当前模式的 prompt 和 temperature | `profile.modes` + `qr_mode_log` |

「设置 → 运行心思和记忆整理」关掉：回复只用人设 + 当前模式 + 上下文，不跑心思和夜里整理，模式在聊天页右上角手动切。

## 什么时候跑

| 流程 | 触发 | 做什么 | 代码 |
|---|---|---|---|
| 回复 | 每轮 | 回复前不调用任何模型 | `routes/api/talk.ts`、`voice/pack.ts` |
| 心思 | ① 每轮回复后异步；② 她沉默 45 分钟时一次（每段沉默只一次） | 输出 `heart`（空 = 不变）、`plans_changed` + 完整 `plans`、`mode`（空 = 不换）、`note`（今天的一句） | `voice/reflector.ts` |
| 到点的打算 | 每 5 分钟的 wake（cron-job.org） | 她最后一条消息在 10 分钟内：先放着；否则调用 `reach` 决定发不发一条推送，发完这些打算算完成 | `reach.ts` |
| 夜里整理 | wake 在当地 04:00–12:00 之间发现昨天还没整理 | 一次调用：整篇重写记得的、写这一天的时间线、明天的打算、明早的心里。床戏这类 `keepActions=false` 的模式里，他的话只留说出口的部分 | `night.ts` |
| 整理今天 | 他的心 → 「现在把今天整理进去」 | 同上，但只改记得的和今天的时间线，不动打算和心里 | `night.ts`（manual） |
| 清空聊天 | 她按下 | 今天还没整理进记忆的消息标 forgotten；清空心里；删掉没定时间的打算。定了时间的、她加的打算和记得的保留 | `store.ts clearRecentConversation` |

## 回复看到的（顺序）

1. 人设（+ 身份）+ 当前模式的 prompt
2. `你记得的：` + 记得的全文
3. `你心里（她看不到，你用做的事体现出来）：` + 心里 + 眼前想做的一件事
4. 亲密设定（当前模式勾了 intimate 时）
5. `现在是…` + 她上一次说话距现在多久 + 今天她来找他的时段
6. 最近 N 条（较早的清然回复只留说出口的话）
7. 这一句

## 心思看到的

人设、身份、故事线、记得的、为什么现在想（刚说完话 / 沉默了多久）、时间事实、最近 7 天时间线、今天的记录、心里、全部打算、模式列表、最近 20 条对话。判断规则都在 prompt 里（设置 → 高级 → 指令 → 内心），可以改：打算写目标不写手段；「这个人我应该认识吗」决定自己补还是问她；分清情趣反抗和真的拒绝。

## 模型

都在设置 → 高级 → 指令里按指令换。默认：回复 grok-4.2（non-reasoning）；心思 `reflect` grok-4.3 medium；夜里整理 `editor` grok-4.3 medium（超时 240 秒）；到点找她 `reach` grok-4.3 low。

## 不再用的

glow（心情数值）、desire / read_her / feel / choice / longings / scene 字段、mode_plan 排程、next_reach、feedback 字段、每 30 轮一次的 ops 式 editor、16 小时 / 30 分钟过期、忙碌表（不再生成，回复也不再有查忙碌的 tool）。旧表都还在，只是不再写入；旧的逐表备份在「高级 → 系统存档」。
