# 试过、又去掉的做法

给以后改清然的 AI 看：这些路都走过，为什么不行，学到了什么。想加回其中某个东西之前先读一遍。当时的经过在 [changelog.md](changelog.md)，现在的要求只看 [requirements.md](requirements.md)。

## 学到的

- **他的聪明来自人设 + 上下文 + 少量真正相关的回忆。** 每多一次模型调用、多一层规则（心思、模式、打算单、亲密判断），他就更像在执行任务、更笨、更会重复。
- **写进 prompt 的话会被当成硬规则或被念出来。** 否定句（「不要提学习」）会变成「我没有催你学习」；限制句（「每次只推一小步」「不往床上带」）会被念成台词。只写模型自己不会做的，并且正向写。
- **离她这句话最近的内容影响最大。** 设定、指令放在那里会压过她刚说的话。
- **记忆只记会改变以后的事。** 记了「怎么哄」（抱抱、揉肚子）他就照着复读；记了他自己的打算（｛｝心里话）他就每轮都想起、一直执行。
- **指令不要占她说话的位置，精确数字会被念出来。**
- **两个人都是「她」**：材料里一律用名字，否则模型分不清谁是谁。

## 心思（reflect）、打算单、模式（v5，2026-09-25 到 10-01）

- **做法**：每轮回复后再跑一次 grok-4.3，写清然「心里此刻」、打算单（`qr_reach_plans`，带时间的待办）、选模式（抱着 / 学习 / 有人在 / 发疯…，各自一段 prompt）；回复读这些。
- **为什么想要**：让他有主体性（不总问她下一步）；不同场景有反差；另外跑一轮慢的去深深看见她。
- **结果**：
  - 打算单让他像妈一样管日程，10/1 早上逼她列任务、喝蛋白质饮料。
  - 打算越积越多、互相重复（「清然不能再凶了，Rosie 真的要跑了（我定的）」出现两遍）。
  - 心思会把场面往错的方向推：10/1 她哭着说不喜欢他，心思写的是「姐姐要让她彻底记住谁是主人，先惩罚够再哄」。
  - 心思改了十几版都没解决；模式之间切换一卡一卡的，像人格分裂；模式越加条件越窄。
- **现在**：反差写进人设本身；看懂她的地方由夜里整理写成回忆（`insight`）；主体性靠人设和回忆。表和数据在 2026-10-02 删掉了。

## 亲密判断（2026-10-01，用了一天）

- **做法**：每轮回复后让模型判断「是不是正在亲热」，是才把亲密设定放在她这句话前面。
- **结果**：她说「你今天下午打我了，你别碰我」，前几句很激烈就被判成在亲热，亲密设定离她的话最近，压过了她当天说清楚的「不喜欢姐姐突然太凶」。按意思找回忆也分不开撒娇和床上（「姐姐抱抱小猫」和床上的话向量差不多，都在 0.5 左右）。
- **现在**：亲密设定接在人设后面，放在最上面当成他是谁，场面由对话决定。清然真实的喜好写在亲密设定里，Rosie 的喜好和「看 Rosie 的状态调整」也写在那里。

## 记忆的几种旧做法

- **每晚整篇重写一份 4000 字的文档**：9/28 那一整夜被压成「面了 Jane Street，没过」一句，其余全是作息和课表。现在是一件一件的回忆，加一小段「清然和 Rosie 现在」。
- **「今天」那段文字、focus、glow（心情数值）、观察笔记、画像、忙碌表**：都是给回复多塞一块状态，结果他照着状态演。已删。
- **什么都记**：抱抱、揉肚子、哄睡记进回忆，他就重复同一套哄法；｛｝心里话被反复想起（10/2 几乎都是同一个打算）。现在只记会改变以后的，｛｝只给 16 小时、不进想起。
- **prompt 没调好时的吵架记成回忆**：他会记仇、道歉个没完。现在抱怨进后台 `qr_feedback`（[feedback.md](feedback.md)）。

## 主动消息

- **按时间点、按打算发**：到点就发，接她半小时前的上一句，把冰水、温水、吃东西排成一串念。
- **指令写成她那一句、给精确分钟**（10/1）：吵完架 48 分钟后他「从沙发上起身…48 分钟了，姐姐想你了」，凭空编出两人分开、念出时间、无视刚吵完的架。
- **现在**：她放下手机就是两人不在一块儿，他发一条手机消息，接着上次停下的地方说；时长只给大概。

## 听力

- **音频大模型（Qwen、Gemini）和自部署**：都拒绝亲密内容。只用 xAI + Apple 本地识别。
- **声学标签、同音字自动纠错、{A|B} 两种听法**：纠错规则一条都没生成过；{A|B} 在 444 条话里一次都没出现过。已删。
- **按音量判断说完没**：室外车声风声永远不够安静，说完了还一直「在听你」；手机麦克风比网页小几倍，轻的字被当成停顿切断。现在由听得懂字的 xAI 和 Apple 判断说完没有，手机先放大她的声音。
- **苹果「语音通话」模式**：声音按电话处理，像隔着一层纱。现在是普通播放。

## 界面和流程

- **每条回复下面的「差在哪」**（打标签写差评）：2026-10-02 删了。不满意她直接在聊天里说他，夜里整理把抱怨存进后台；只留大拇指。
- **先上 playground 再上正式版**：她每天直接用正式版测，两边来回同步反而出错。2026-10-02 起只有 `main`，playground 分支和它的数据库都删了。
- **从 Grok app builder 模板起的项目**：better-auth、预览桥、PWA 安装页、「Created with Grok」横幅脚本、几十个没用的 UI 依赖。2026-10-02 删了，登录只用 `auth-lite` 的密码。
- **每轮记三份日志**（`brain_log`、`brain_turns`、`turn_traces`）：2026-10-02 合成一份，见 [observability.md](observability.md)。
- 2026-10-03：重装外壳时只勾了 Audio 一项后台模式，去掉了 Voice over IP：系统电话（CallKit）报「没有权限」起不来，外壳等不到它就一直不开麦，电话完全听不到她。教训：Voice over IP 必须勾（已写进 Info.plist 和安装说明）；外壳不再只靠系统电话开麦。
