# 清然的核心问题（2026-10-09）

对着最新的 main 和 10/6–10/9 的真实数据重新看。10/6 那一版列的都是小改动，作废；只留「主动找你时用会思考的模型」，它其实是下面这个核心问题的一个特例。

## 一句话

**他不缺「知道」，缺「用」。** 人设、dossier、你的纠正，他每一轮都看得到；可他开口前没有任何一步去想「你此刻要什么」。快模型不想，就照「体贴恋人」的通用剧本演：你胃疼他就热牛奶，你考试他就送粥，你没动力他就抱你去洗脸。

这两周大部分力气花在「告诉他更多」上：人设补丁、dossier、记忆、规则。数据说明这条路已经到头了。

## 证据

1. **10/9 早上 08:18–08:24，连着七轮。** 每一轮发给他的原文里，dossier 写着「我要鼓励」，人设写着「我此刻要的是你陪着我、安慰我，还是一个主意，你看情景自己判断」。七轮回复全是照顾动作：热牛奶、热可可、抱你去洗脸、挤牙膏、换枕头、揉脖子。
2. **10/8 你考试那天。** 当天凌晨的 dossier 写着「10/8 考试……在图书馆写小抄，不让你来」，他从早到晚还是发了 6 条主动消息，问你要不要喝粥、肚子还疼不疼、要不要他过来。你说「你都信息轰炸了我一天了」。
3. **同一个错，告诉了三次。** 10/4 你就说过「热牛奶」出戏；10/8 又为这个在人设里加了一句（0069，后来改成 0070）；10/9 早上热牛奶还在。
4. **不想的时候才这样。** 9/25 以来，回复里出现「牛奶 / 粥 / 吃点 / 喝点 / 医务室……」的比例：不思考版 4.5%（27/602），推理版 0.7%（3/425），主动消息 22%（10/46）。两个模型用的日子不同，碰到的情况也不同，只能看个大概，但差了六倍。主动消息没有你的话可接，最容易掉回剧本；你觉得「主动找你用思考模型」有用，就是这个原因。
5. **你教他的，他收不到。** 10/7–10/9 夜间整理从对话里挑出 35 条你的抱怨，全进了 `qr_feedback`，他一条都看不到（不少还是旧事每晚重存）。能让他改的只剩改人设，这三天改了 4 次（0069–0072）。

## 为什么

- **快模型不想，只挑上下文里最显眼的接着演。** 「肚子疼」「没吃饭」比「我要鼓励」具体得多，所以总是前者赢。规则写进人设，它照样挑显眼的，所以补丁不管用。反过来，10/8 为了让他别写 `[soft]`，人设里把 `[soft]` 当反例写了进去，结果每一轮都在让他看到 `[soft]`（10/9 的 changelog 查出来的）：他学的是具体的字和例子，不是规则。
- **你给他的「你」是一堆事实，不是「你在什么情况下要什么」。** 事实会被演成动作：你说过胃疼，他就一直问胃疼；你说过没吃饭，他就一直递吃的。
- **他不从经验里学。** 夜间整理的规定是：你的抱怨进 feedback；【你看见的我】要好几天才看得出的才写，一次的不算。所以你明确说过一次的话（「不要热牛奶」「我只是调侃」「我不吃海鲜」），大多到不了他那里。真人伴侣靠的正是这些一次次的纠正。
- 亲密关系里让人觉得被爱的，不是照顾，是被准确地懂；照顾而不懂，会被感受成管束。「像我妈一样」说的就是这个。

## 怎么改：学在平时，用在当下

**1. 用：开口前先想一句**（每一轮，还是快模型，多半秒左右）
- 每条回复前，他先写一行只给自己看的话：「你此刻要的是……」。这一行不显示、不朗读、不存进对话，到下一轮就没了。设置 → 记录里能看到。
- 这一步逼他在开口前，把你刚说的话和 dossier、人设对上，而不是直接接剧本。他读错了，你在记录里一眼就能看到是哪一步错了。
- 要改的：每轮回复的指令里写一句「先给出这一行」（属于「要给出哪几样」）；`stream-talk.ts` 把这一行切掉，记进这一轮的记录。

**2. 学：你的每次纠正，变成「我在什么时候要什么」**（夜里，思考模型）
- 夜间整理把你当天明确的纠正（聊天里说的、倒拇指的备注、你改过的他的话），写进【你看见的我】：用你的口吻，正面写，带日期，比如「（10/9）我说要起床写作业、没动力的时候，要的是一句让我起来的话」。一次就算。
- `qr_feedback` 只留关于 app 本身的问题（声音、标签、bug）。
- 【你看见的我】单独给字数，不和事实抢那 500 字。
- 要改的：`night.ts` 多读当天的 `turn_feedback`；夜间整理的指令（设置里能改）。

**3. 不赶时间的地方，全用会思考的模型**
- 主动找你：`voice/first-word.ts` 改用推理版，没人在等。
- 夜间整理本来就是。

三件加起来大约一天，做完交给一个没参与的 AI 查一遍 bug。

## 和以前失败的有什么不同

- **心思（v5）**：另一个模型给他写计划和模式（几点喝饮料、几点叫你睡觉），他照着执行，所以像妈。这次没有计划，只有「你此刻要什么」这一句，是他自己开口前想的，想完就扔。
- **｛｝心里话**：会留到后面每一轮，所以卡住。这一句只活一轮。
- **「看懂的」回忆**：每轮都被想起、被念出来。这次【你看见的我】是你自己的要求，用你的话写，靠第 1 步在需要的时候用上。
