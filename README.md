# 清然

Rosie 的语音聊天工具：按住说话 / 电话免提，Eve 朗读，长期记忆，可编辑 system prompt。

这是从 Grok 应用构建器导出的源码（含语气词识别改回「只信语音转写」的版本）。

## 本地运行

```bash
npm install
npm run dev
```

默认在 `0.0.0.0:8080`。

## iOS 原生壳（只给自己用）

网页版做不到微信那样的后台通话。`ios/` 里是给 iPhone 用的原生壳：系统麦克风、后台音频、CallKit。

你要亲自做的步骤写在 **[ios/安装说明.md](ios/安装说明.md)**。需要 Mac、99 美元的 Apple 开发者账号，以及先把这次网页发布到现有的 grok.me 地址。

日常改功能：推 GitHub → 发布到同一个 grok.me → 手机打开清然即是新版，不用重装。只有改 `ios/` 里的原生壳才要再用 Xcode 装一次。

## 说明

- 聊天记录和记忆存在数据库里，跟发布用的域名绑定。换一个 grok.me 链接会是空库，不会自动带上旧站的 prompt / 记忆。
- 不要提交 `.env` 或 API 密钥。
